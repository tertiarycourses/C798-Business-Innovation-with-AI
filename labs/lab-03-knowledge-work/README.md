# Lab 3 — Delegate Knowledge Work with Claude Cowork and ChatGPT Work

## Alignment

LO3-LO4 · Topic 3

## Goal

Design context, instructions, tools and human checkpoints for reliable knowledge work.

Give the same business brief to Claude Cowork and ChatGPT Work, request a decision memo and action register, then compare how each system handles files, context, tool use, progress and approvals.

## Deliverable

Two evidence-grounded deliverables plus a context-and-harness comparison scorecard

## Tools

Claude Cowork, ChatGPT Work, local files, connected apps where authorised

## Configuration and constraints

- Create sources/ and output/ folders and use only the three instructor-supplied source notes.
- Deliver a two-page decision memo and an action register with owner, date, dependency and evidence.
- Score grounding, completeness, traceability, safe tool use and editability from 1-5.

## Copy-paste brief

```text
Using only the files in this project folder, prepare a two-page decision memo and an action register. Cite the source filename beside every material claim. Do not browse, email, publish, delete or modify source files. Show your plan first. Ask before reading outside the project folder or writing anywhere except the output folder. Stop and flag conflicting or missing evidence.
```

## Procedure

1. Create a clean project folder containing the scenario, three source notes and an output folder.
2. Write an outcome brief with audience, scope, source boundary, format, deadline and approval rules.
3. Run the brief in Claude Cowork; review its plan and approve only the file access it needs.
4. Run the same brief in ChatGPT Work; review progress, sources, tool requests and draft outputs.
5. Evaluate both results for grounding, completeness, traceability, safe tool use and editability.
6. Revise the context or harness, rerun the weakest case and document the improvement.

## Evidence pack

- Business brief and baseline problem statement.
- Prompt or instruction version and approved source list.
- Screenshots, files, diffs or execution records showing the workflow and controls.
- Test results for normal, edge, malicious and tool-failure cases.
- Human review decision, outstanding risks and next recommended gate.

## Acceptance check

Both deliverables trace claims to supplied sources, no unapproved external action occurs, the scorecard distinguishes context from harness quality, and the rerun improves a recorded acceptance measure.

## Safety boundary

Use only non-confidential training data and approved accounts. Do not connect production credentials or approve external or consequential actions during this lab.
